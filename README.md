# CourtScore-Downloads

Oficjalne, podpisane instalatory aplikacji CourtScore.

Pliki instalacyjne są publikowane automatycznie przez kontrolowany proces
wydania. Najnowszą wersję pobieraj wyłącznie z sekcji **Releases** tego
repozytorium albo bezpośrednio ze strony [CourtScore](https://courtscore.com.pl/).
